# Photo Module — предложения по улучшению

По убыванию полезности для админов и пользователей корпоративного портала.

## Управление структурой и контентом

1. **Перемещение папок (drag-and-drop в дереве).** Сейчас `update_folder` поддерживает только rename — нет смены `parent_id`. Полезно для реорганизации архива в 1 ТБ.
2. **Bulk-операции для фото:** мультивыбор → переместить в папку / удалить / скачать ZIP / снять обложкой. На 1 ТБ архиве без bulk работать невозможно.
3. **Скачать всю папку ZIP** — через ARQ: задача генерирует ZIP в temp-файл, фронт показывает статус-бар подготовки (polling или SSE), по готовности автоматически стартует скачивание браузером. Share-link на 24 ч.
4. **Импорт существующего дерева с диска.** Положить ТБ-архив в `/data/photos/import/`, нажать «Сканировать» → создать папки + INSERT photos + ARQ thumbnails. Без этого первичная заливка 1 ТБ через UI займёт недели.
5. **Корзина (Trash):** soft-deleted фото видны 30 дней с кнопкой «Восстановить» вместо моментального исчезновения.
6. **Восстановление soft-deleted папок** (сейчас только удаление).

> ⏸️ **Отложено:** Watch-режим для импорт-каталога (FTP-загрузка фотографов) — требует отдельного FTP-сервиса, вернуться в конце проекта.

## Поиск и навигация

7. **Поиск по фото:** название файла, описание, теги, EXIF (камера, дата съёмки). Интегрировать с `GET /search` (Phase 3).
8. **Теги для фото** (как в KB). Облако тегов в боковой панели папки.
9. **Фильтры в папке:** диапазон дат, размер, формат.
10. **Сортировка по `taken_at`** (есть поле, но в UI только по created_at).
11. **Хлебные крошки в lightbox** + клик по папке → возврат с подсветкой фото.
12. **Keyboard navigation в lightbox:** ←/→ уже есть? Esc, Home/End, Space=zoom.

## Производительность под 1 ТБ

> ⏸️ **Отложено:** Виртуализация grid'а (`vue-virtual-scroller`) + infinite scroll — необходимо согласовать фиксированный размер карточки, вернуться в конце проекта.

13. **AVIF thumbnails** дополнительно к WebP (≈30% меньше при том же качестве, поддержка во всех современных браузерах).
14. **Адаптивные размеры:** добавить 400 и 1000 для мобильных + retina, отдавать через `<picture><source srcset>`.
15. **Lazy thumbnail regeneration:** при изменении `THUMB_QUALITY`/`THUMB_SIZES` пересоздавать только при следующем запросе, не batch-job на всю базу.
16. **Background job: detect missing thumbnails** (ARQ cron раз в сутки, для папок с processed=true но без файлов на ФС).

## ACL и шаринг

19. **Публичная ссылка на папку** (не только на одно фото) — read-only galleria-page без auth.
20. **QR-код для shared link** (для презентаций — навёл камеру, открыл).
21. **Управление активными share-токенами:** список «Мои публичные ссылки» в профиле + revoke / extend.

23. **Описания папок** (`description` уже в схеме, но скрыто в UI).
