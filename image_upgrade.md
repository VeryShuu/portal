# Photo Module — предложения по улучшению

По убыванию полезности для админов и пользователей корпоративного портала.

## Управление структурой и контентом

1. **Перемещение папок (drag-and-drop в дереве).** Сейчас `update_folder` поддерживает только rename — нет смены `parent_id`. Полезно для реорганизации архива в 1 ТБ.
2. **Bulk-операции для фото:** мультивыбор → переместить в папку / удалить / скачать ZIP / снять обложкой. На 1 ТБ архиве без bulk работать невозможно.
3. **Скачать всю папку ZIP** (стримом, через ARQ → temp-файл + share link на 24 ч).
4. **Импорт существующего дерева с диска.** Положить ТБ-архив в `/data/photos/import/`, нажать «Сканировать» → создать папки + INSERT photos + ARQ thumbnails. Без этого первичная заливка 1 ТБ через UI займёт недели.
5. **Watch-режим для импорт-каталога:** новый файл появился на ФС → автоматически добавлен в БД (для FTP-загрузки фотографов).
6. **Корзина (Trash):** soft-deleted фото видны 30 дней с кнопкой «Восстановить» вместо моментального исчезновения.
7. **Восстановление soft-deleted папок** (сейчас только удаление).

## Поиск и навигация

8. **Поиск по фото:** название файла, описание, теги, EXIF (камера, дата съёмки). Интегрировать с `GET /search` (Phase 3).
9. **Теги для фото** (как в KB). Облако тегов в боковой панели папки.
10. **Фильтры в папке:** диапазон дат, only-with-GPS, размер, формат.
11. **Сортировка по `taken_at`** (есть поле, но в UI только по created_at).
12. **Хлебные крошки в lightbox** + клик по папке → возврат с подсветкой фото.
13. **Keyboard navigation в lightbox:** ←/→ уже есть? Esc, Home/End, Space=zoom.
14. **Карта (если EXIF GPS не stripped):** Leaflet + OpenStreetMap, маркеры по координатам (отдельный режим, GPS strip toggle per-folder).

## Производительность под 1 ТБ

15. **Виртуализация grid'а** (`vue-virtual-scroller`). Без неё 5000 фото в папке вешают браузер.
16. **Постраничная подгрузка с infinite scroll** вместо «Показать ещё».
17. **Дедупликация по SHA-256.** Хеш считается ARQ при загрузке → блокирует upload дубля или предлагает «уже есть в папке X». Экономит десятки ГБ на корпоративном архиве.
18. **AVIF thumbnails** дополнительно к WebP (≈30% меньше при том же качестве, поддержка во всех современных браузерах).
19. **Адаптивные размеры:** добавить 400 и 1000 для мобильных + retina, отдавать через `<picture><source srcset>`.
20. **Lazy thumbnail regeneration:** при изменении `THUMB_QUALITY`/`THUMB_SIZES` пересоздавать только при следующем запросе, не batch-job на всю базу.
21. **Background job: detect missing thumbnails** (ARQ cron раз в сутки, для папок с processed=true но без файлов на ФС).

## ACL и шаринг

22. **Группы Keycloak:** ACL уже поддерживает `subject_type=group`, но в UI «Поделиться папкой» только пользователи. Добавить выбор групп (Marketing, Finance) с автоподгрузкой из Keycloak Admin API.
23. **Время действия прав:** `expires_at` на permission (доступ подрядчику до конца проекта).
24. **Публичная ссылка на папку** (не только на одно фото) — read-only galleria-page без auth.
25. **QR-код для shared link** (для презентаций — навёл камеру, открыл).
26. **Управление активными share-токенами:** список «Мои публичные ссылки» в профиле + revoke / extend.

## UX и отображение

27. **Cover photo для папки** — поле уже есть в БД (`cover_photo_id`), но не используется в UI дерева. Показывать миниатюру вместо иконки папки.
28. **Описания папок** (`description` уже в схеме, но скрыто в UI).
29. **Слайдшоу-режим** в lightbox с автоперелистыванием (5/10/30 сек).
30. **Drag-and-drop загрузка:** перетащил файлы из Проводника прямо на grid папки.
31. **Прогресс-бар на multi-upload** (по файлу + общий) с возможностью отмены.
32. **EXIF-панель в lightbox** (камера, объектив, диафрагма, ISO, дата) — toggle.
33. **Сравнение «до/после»** (split-view двух фото) — для отчётов о ремонтах/строительстве.

## Аудит и аналитика

34. **«Кто скачал моё фото»** — список из `audit_log` для uploader+ владельца.
35. **Топ-10 просмотренных фото месяца** (виджет на главной, рядом с PhotosWidget).
36. **Storage usage per folder/department** в Admin UI.

## Безопасность

37. **Watermark при публичном шаринге** (опция per-folder: накладывать «Confidential / portal.company.local» через Pillow).
38. **Антивирус-сканирование загрузок** через ClamAV (как у вложений новостей).
39. **Detect screenshots/forwarding:** добавить уникальный fingerprint в EXIF при отдаче по share-link для leak-tracking.
