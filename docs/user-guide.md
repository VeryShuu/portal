# Гайд пользователя

> Корпоративный портал — единое окно к новостям, базе знаний, файлам,
> ярлыкам сервисов, фото- и видеогалерее.

---

## 1. Вход

1. Откройте `https://portal.<вашакомпания>.ru` (URL даёт администратор).
2. Кнопка **Войти через корпоративный SSO** — переведёт на Keycloak,
   где вы введёте свой корпоративный логин/пароль (или MFA).
3. После входа попадаете на главную: новости, ярлыки, закладки, виджет
   фотогалереи.

⚠️ Портал доступен **только из внутренней сети или VPN**.

---

## 2. Главная

- **Hero** — приветствие, текущее время, кастомный подзаголовок.
- **Новости** — последние и закреплённые. Клик → детальная страница.
- **Ярлыки сервисов** — переходы в ITSM/HR/BI с автоматическим SSO.
  Можно скрыть ненужные через «Профиль → Скрыть ярлык».
- **Закладки** — ваши личные ссылки. Drag-and-drop сортировка.
- **Фотогалерея** — последние загруженные фото в доступных папках.
- **Поиск (Ctrl + K)** — мгновенный поиск по новостям, статьям KB,
  ярлыкам, пользователям. Поддерживаются опечатки.

---

## 3. Новости

- **Список:** фильтры по категории, дате, отделу.
- **Детальная:** WYSIWYG-контент, обложка, галерея, вложения.
- **Экспорт:** PDF / HTML / Markdown — кнопки в шапке статьи.
- **Создать новость** (роль `editor+`):
  - Заголовок, текст (TipTap-редактор: ссылки, изображения, цитаты, код).
  - Обложка (рекомендуется 1600×900).
  - Галерея (`drag-and-drop`).
  - Вложения (любые файлы до 50 МБ).
  - **Таргетинг**: по отделам или ролям — увидят только указанные.
  - **Отложенная публикация** (`publish_at`) и **архивация** (`archive_at`).

---

## 4. База знаний

- **Дерево разделов** слева; статьи — внутри.
- **Поиск** работает с опечатками (нечёткий через `pg_trgm`).
- **Создать статью** (роль `editor+`):
  - Markdown-редактор (TipTap c dual-mode: визуальный/исходник).
  - Автосохранение каждые 30 сек.
  - **Теги** для группировки.
  - **Версионность** — можно посмотреть историю и откатить.
  - **Доступ** (вкладка): viewer / editor / manager + наследование от
    раздела.
- **«Полезна?»** под статьёй — голосуйте, авторы видят оценку.
- **«Предложить правку»** — отправить замечание автору.
- **Экспорт** — PDF / DOCX / Markdown.

---

## 5. Файлы (Nextcloud)

- Левая панель — дерево корпоративных папок.
- Правая — содержимое (файлы и подпапки).
- Двойной клик по `.docx`/`.xlsx`/`.pptx` → открывается в Collabora
  (отдельная вкладка) для совместного редактирования.
- Загрузка drag-and-drop. Лимит — обычно 100 МБ на файл.
- Скачивание сохраняет оригинальное имя (включая кириллицу).

⚠️ Удаление файла **через портал** удаляет его и в Nextcloud. Восстановление
— через корзину Nextcloud (admin) или из бэкапа.

---

## 6. Фотогалерея

- Дерево папок слева; миниатюры справа.
- Клик по фото → lightbox: zoom, поворот, скачать, поделиться.
- **Ссылка-поделиться** — публичная ссылка с TTL (1/7/30/90 дн или
  бессрочно). Получатель видит фото без логина в портал.
- **QR-код** — для быстрого шеринга папки на мобильный.
- Загрузка: drag-and-drop из Проводника. Поддерживаются HEIC/HEIF
  (конвертируются в WebP).
- **Bulk-операции:** выделить несколько фото → переместить / удалить /
  скачать ZIP.
- **Корзина** — удалённые хранятся 30 дней, можно восстановить.

---

## 7. Профиль

«Аватар → Профиль»:
- Аватар (PNG/JPG, обрезка по кругу).
- Статус присутствия (на месте / занят / в отпуске).
- Язык интерфейса (RU / EN).
- Уведомления (email / in-app).
- Скрытые ярлыки (можно вернуть обратно).
- Смена пароля (только для локальных аккаунтов).

---

## 8. Уведомления

- **Колокольчик** в шапке — счётчик непрочитанных.
- Push через SSE — приходят в реальном времени.
- Email — настраивается в профиле.
- Типы: упоминание в новости, новый комментарий к вашей статье,
  предложенная правка, шаринг файла.

---

## 9. Hotkeys

| Клавиша | Действие |
|---------|---------|
| **Ctrl + K** | Глобальный поиск |
| **Esc** | Закрыть lightbox / модалку |
| **← / →** | Lightbox: предыдущее / следующее фото |
| **Space** | Lightbox: zoom |
| **Home / End** | Lightbox: первое / последнее фото |

---

## 10. Куда писать, если что-то не работает

- Сначала **F5** — кэш SPA мог застрять.
- Если ошибка повторяется — скриншот + URL + время → ИТ-поддержка
  (контакт в подвале портала).
- Жалобы по контенту (кому-то нагрубили, статья устарела) — кнопка
  «Сообщить» внизу любой статьи или новости.
