# docs/wip — планы активных фич (handoff между сессиями)

Здесь живут планы задач, которые **не закрываются за одну сессию** агента.
См. раздел «Работа между сессиями» в `../../AGENTS.md`.

## Правила

- Один файл на фичу: `docs/wip/<feature>.md` (kebab-case, напр. `staff-directory-export.md`).
- Создаётся, как только ясно, что задача длиннее одной сессии.
- В начале сессии агент читает соответствующий план + `git log --oneline -15` + `git status`.
- В конце сессии агент обновляет чеклист и блок хэндоффа в плане.
- **Удаляется после завершения фичи** (когда задача смёржена) — каталог отражает только активную работу.
- Шаблон — `_TEMPLATE.md`.
