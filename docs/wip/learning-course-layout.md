# Карточка курса: компоновка и статусы

## Цель
Сделать обложку, программу курса и прогресс понятнее в портале и внешнем кабинете обучения.

## Решения по ходу
- 2026-08-31: пользователь попросил создать PR с уже готовой UI-частью; позиционирование обложки не блокирует этот PR и остаётся отдельной задачей.
- 2026-08-31: материалы/тесты слева, описание справа; под названием описание удалено. В исходном сообщении есть противоречащая фраза «описание только слева»; реализована основная формулировка, пользователь уведомлён.
- Описание сохраняется как обычный текст с переносами; пустое описание не резервирует колонку. На узком экране блоки идут друг под другом.
- Пройденность обозначается текстом, значком и цветом. Непройденный элемент называется «Не пройден», поскольку API не отличает не начатые элементы от неудачных/брошенных попыток.
- Кнопка завершённого теста «Результаты теста» открывает компактное модальное окно, без автоматического начала новой попытки и без увеличения высоты программы курса.
- 2026-08-31: по дополнительному замечанию пользователя результат и прохождение теста перенесены в общее окно. При исчерпанном лимите нет отключённой кнопки старта; доступны только подходящие действия: старт, повтор или продолжение. Ошибка загрузки истории предлагает повтор загрузки и не разрешает старт вслепую.
- Escape/клик снаружи закрывают результат с возвратом фокуса. Во время прохождения они не закрывают окно; явное закрытие требует подтверждения потери неотправленных ответов.
- Обложка выше, ширина ограничена стандартным токеном. Вертикальный исходник курса 13 (634×980) всё равно кадрируется при показе в горизонтальном контейнере.
