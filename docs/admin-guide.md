# Гайд администратора портала

> Аудитория: пользователь с ролью `admin`. Все настройки выполняются
> через UI, без ручной правки `.env` (после первичного bootstrap'а).

---

## 1. Вход

1. Откройте `https://<portal-host>/login`.
2. **Локальный admin (bootstrap):** введите `ADMIN_EMAIL` / `ADMIN_PASSWORD`
   из `.env`. После первого входа смените пароль в профиле.
3. **SSO:** нажмите «Войти через Keycloak». Если это ваш реальный аккаунт,
   попросите другого admin'а повысить вашу роль и используйте уже SSO.

---

## 2. Раздел «Настройки» (admin-only)

### 2.1. Пользователи и роли

«Администрирование → Пользователи»:
- Список всех `users` (синхронизированных + локальных).
- Кнопка **Изменить роль** → `reader` / `editor` / `admin`.
- **Сбросить пароль** (только для `auth_source = local`).
- **Создать локального пользователя** (для аварийного доступа).
- **Запустить синхронизацию из Keycloak** — выгребает новых сотрудников
  из realm и добавляет в `users`.

### 2.2. Ярлыки сервисов (главная страница)

«Администрирование → Ярлыки»:
- Категории: ITSM, HR, BI, прочее.
- `supports_sso=true` → на клике передаётся `id_token_hint` (для систем
  с SSO Keycloak).
- Иконка: PNG/SVG, 64×64.

### 2.3. Оформление (branding)

«Администрирование → Оформление»:
- **Название портала** и слоган — отображаются в шапке и `<title>`.
- **Accent color** — основной цвет MAGE-палитры (color picker).
- **Favicon** — заменяет `/favicon.ico`.
- **Login background** — фон страницы входа.
- **Welcome subtitle** — подзаголовок hero-блока.
- **Баннер**: текст + тип (info/warning/error/success) + дата автоскрытия.

Все изменения применяются без рестарта — обновите страницу в браузере.

### 2.4. Модули

«Администрирование → Модули» (toggle включения + настройки):
| Модуль | Назначение | Поля |
|--------|-----------|------|
| Photos (фотогалерея) | Собственный модуль | размер thumbnail, лимит quota |
| Nextcloud (файлы) | WebDAV + Collabora | URL, App Password, root folder |
| Видеогалерея (внешняя) | iframe embed | URL, whitelist доменов |

Кнопка **Проверить соединение** для каждого модуля.

### 2.5. Система

«Администрирование → Система»:
- **CIDR allowlist** — из каких подсетей пускаем (валидация при сохранении).
- **TLS-сертификат** — upload `.crt` + `.key` (сразу применяется через
  reload nginx).
- **Лимиты загрузки** — `MAX_UPLOAD_SIZE_MB`, размер вложений новостей.
- **Уровень логов** — DEBUG / INFO / WARNING / ERROR (применяется
  динамически).
- **Перезагрузить Nginx** — кнопка на случай ручной правки конфигов.

### 2.6. Keycloak

Поля: URL, realm, OIDC client_id/secret, Sync client_id/secret.
Кнопки: **Проверить OIDC**, **Проверить sync**, **Запустить синхронизацию**.
Статус последней синхронизации виден в карточке.

### 2.7. Email (SMTP)

Host, port, from, username, password, TLS/STARTTLS. Кнопка **Отправить
тестовое письмо** проверяет связность.

### 2.8. Аналитика

KPI: всего пользователей / активных за 24 ч; статьи KB; новости; файлы.
Топ-5 статей, новостей, файлов за последние 14 дней. Графики активности.

### 2.9. Аудит

Фильтры: пользователь, тип события, ресурс, IP, период, поиск.
Экспорт CSV (до 100 000 строк). Глубина журнала — 12 месяцев
(старые партиции автоматически дропаются).

## 3. Регулярные задачи

| Что | Как часто | Где смотреть |
|-----|-----------|--------------|
| Синхронизация с Keycloak | автоматически каждый час | «Настройки → Keycloak → Статус» |

## 4. Что делать, если...

### Пользователь не может войти через SSO
1. Проверить, что он есть в Keycloak realm.
2. Проверить mapper'ы — без `email` портал не сможет создать `users`.
3. Логи: `docker compose logs backend | grep auth.callback_failed`.

### Файлы пропали из «Файлы → Корпоративные документы»
1. Проверить связь с NC: «Настройки → Модули → Nextcloud → Проверить».
2. Проверить, что `portal-svc` в NC не отключён и App Password не отозван.
3. Если папка переименована в NC — обновите `NC_FILES_ROOT`.

### Поиск ничего не находит
1. Проверить FTS-конфигурацию: `psql -c "\dF russian_hunspell"`.
2. Если пусто — пересобрать `postgres` образ (нужен `hunspell-ru`).
3. `REINDEX INDEX kb_articles_fts_idx;` (нечасто, после массового импорта).

### Vue показывает «Соединение потеряно»
SSE отвалился (типично через 60 минут). Перелогин или F5.

### Логи переполнили диск
Логи ротируются json-file по 50 МБ × 5 файлов с gzip — лимит ~250 МБ
на сервис. Если диск всё равно полон — проверить `docker system df`,
почистить старые образы `docker image prune`.

## 5. Безопасность

- **Бэкапы `.env` и `system_data/secrets/`** — в secret-manager, не в git.
- **Ротация секретов** раз в 90 дней (см. `docs/deploy.md` §9).
- **OWASP ZAP** прогонять перед каждым релизом: `./security/zap-scan.sh`.
- **Audit-журнал** проверять еженедельно на аномалии (массовые скачивания,
  смены ролей).
