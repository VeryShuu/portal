# 1. HIGH

### [HIGH-7] Нет защиты от удаления/понижения собственного аккаунта администратором
- **Файл:** `backend/app/api/users.py:213-251`, `375-418`
- **Описание:** Admin может разжаловать или удалить самого себя — и если это единственный admin, система блокируется. Bootstrap-admin не защищён.
- **Риск:** Lockout, требуется ручная правка БД.
- **Рекомендация:** Запретить admin'у изменять роль и удалять собственный аккаунт (`if target_user.id == current_user.id: raise 400`). Этого достаточно — когда останется один admin, он просто не сможет себя понизить, а удалить кого-то другого вреда не нанесёт.
- **Простыми словами:** Администратор может случайно понизить себя в правах или удалить — и если он последний, никто не сможет управлять системой. Достаточно просто запретить ему действия над собственным аккаунтом.

# 2. MEDIUM

### [MEDIUM-6] `email_identifier` обходится через альтернативный Content-Type
- **Файл:** `backend/app/core/limiter.py:28-41`
- **Описание:** Парсится только JSON. При отправке `application/x-www-form-urlencoded` лимит по email обходится.
- **Рекомендация:** Парсить multipart/form, либо принудительно требовать JSON для `/auth/local/login`.
- **Простыми словами:** Ограничение на количество попыток входа по email работает только для запросов в формате JSON. Если отправить тот же запрос в другом формате — ограничение не сработает и можно пробовать пароли без ограничений. Нужно принимать только JSON или уметь читать email из любого формата запроса.

### [MEDIUM-8] Idempotency не покрывает обязательные пути
- **Файл:** `backend/app/middleware/idempotency.py:9-15`
- **Описание:** AGENTS требует `/files/upload` — отсутствует в whitelist. `/notifications/send` добавлен, `/files/upload` — нет.
- **Рекомендация:** Добавить `/api/v1/files/upload` (уточнить точный путь endpoint) или обновить AGENTS.
- **Простыми словами:** Защита от дублирования запросов не настроена для загрузки файлов, хотя документация прямо требует её наличия. Нужно добавить этот путь в список защищённых.

### [MEDIUM-12] `import_article_md` читает весь файл в память
- **Файл:** `backend/app/api/kb_extra.py:922`
- **Описание:** `await file.read()` без проверки `file.size`/bounded read. Для vault zip лимит есть, для одиночного MD — нет.
- **Рекомендация:** Применить `_kb_import_max_bytes()` как в vault: проверка `file.size`, чтение `limit + 1`, 413 при превышении.
- **Простыми словами:** При импорте Markdown-файла в базу знаний файл целиком загружается в память без ограничения на размер. Очень большой файл может исчерпать оперативную память сервера. Нужно ограничить максимальный размер, как уже сделано для zip-архивов.

### [MEDIUM-13] `cleanup_idempotency_keys` некорректный SQL
- **Файл:** `backend/app/worker/tasks/audit.py:134`
- **Описание:** `DELETE ... RETURNING count(*)` — invalid PG syntax.
- **Риск:** Daily cron-задача очистки idempotency-keys падает; записи накапливаются.
- **Рекомендация:** `WITH deleted AS (DELETE ... RETURNING 1) SELECT count(*) FROM deleted` либо `result.rowcount`.
- **Простыми словами:** Ежедневная задача очистки устаревших записей-дубликатов содержит синтаксически неверный запрос к базе данных — она падает при каждом запуске и никогда не убирает старые данные. База данных постепенно засоряется мусором. Нужно исправить запрос.

### [MEDIUM-16] Deprecated `nc_user_id_field` в config.py
- **Файл:** `backend/app/core/config.py:54`
- **Описание:** ADR-032/AGENTS говорят что не нужен, поле осталось.
- **Рекомендация:** Удалить или пометить deprecated.
- **Простыми словами:** В конфигурации приложения осталось устаревшее поле, которое по документации давно должно было быть удалено и нигде не используется. Оно не вредит напрямую, но вносит путаницу при работе с конфигурацией. Нужно удалить это поле.

### [MEDIUM-20] `window.location.href = photoGalleryUrl` без валидации протокола
- **Файл:** `frontend/src/components/AppLayout.vue:337`
- **Описание:** Admin контролирует URL; нет проверки `^https?://`.
- **Риск:** `javascript:` URL → XSS при компрометации admin.
- **Рекомендация:** `if (/^https?:\/\//i.test(url))` перед присвоением.
- **Простыми словами:** При переходе по ссылке фотогалереи не проверяется, что адрес начинается с http:// или https://. Если администратор (или злоумышленник с его правами) задаст адрес вида `javascript:...` — это выполнит произвольный код в браузере пользователя. Нужно проверять протокол перед переходом.

### [MEDIUM-21] `router.push(n.link)` с server-controlled значением
- **Файл:** `frontend/src/components/NotificationsDropdown.vue:168`
- **Описание:** `n.link` без валидации передаётся в `router.push()`.
- **Рекомендация:** `if (n.link?.startsWith('/')) router.push(n.link)`.
- **Простыми словами:** При нажатии на уведомление пользователь переходит по ссылке из уведомления без проверки, что это внутренняя ссылка нашего портала. Если сервер отдаст внешний адрес — пользователь может оказаться на постороннем сайте. Нужно проверять, что ссылка начинается с "/" (то есть ведёт на наш портал).

# 3. LOW

### [LOW-6] Минимальная версия TLS не задана в шаблоне nginx
- **Файл:** `system_data/nginx/entrypoint.sh`
- **Описание:** Нет `ssl_protocols TLSv1.2 TLSv1.3`. AGENTS декларирует "TLS 1.2+".
- **Рекомендация:** Добавить `ssl_protocols`, `ssl_ciphers`, `ssl_prefer_server_ciphers off`.
- **Простыми словами:** В шаблоне конфигурации веб-сервера не указана минимально допустимая версия шифрования соединения. По умолчанию могут использоваться устаревшие небезопасные версии. Нужно явно прописать "не ниже TLS 1.2".

### [LOW-7] curl в postgres Dockerfile без необходимости
- **Файл:** `postgres/Dockerfile:5`
- **Описание:** Healthcheck использует `pg_isready`, curl не нужен.
- **Рекомендация:** Удалить curl.
- **Простыми словами:** В образе базы данных установлена утилита curl, которая нигде не используется — проверка работоспособности делается другим инструментом. Лишние программы увеличивают размер образа и расширяют поверхность для потенциальных атак. Нужно удалить её.

### [LOW-8] Отсутствие trap-focus в NotificationsDrawer
- **Файл:** `frontend/src/components/NotificationsDropdown.vue:25`
- **Описание:** `:trap-focus="false"` — клавиатурная навигация выходит из дравера.
- **Рекомендация:** Убрать или обосновать.
- **Простыми словами:** При открытии панели уведомлений с клавиатуры фокус не удерживается внутри панели — пользователи, которые пользуются клавиатурой или программами чтения экрана, могут случайно "выйти" за её пределы. Нужно включить удержание фокуса или объяснить, почему оно намеренно отключено.

### [LOW-9] localStorage чтение без валидации схемы
- **Файлы:** `frontend/src/composables/useRecentArticles.ts:11`, `frontend/src/components/GlobalSearch.vue:280`
- **Описание:** `JSON.parse` без проверки типа.
- **Рекомендация:** `Array.isArray + filter по shape`.
- **Простыми словами:** Данные из локального хранилища браузера (история поиска, недавние статьи) читаются без проверки их структуры. Если данные повреждены, устарели или подменены — приложение может сломаться. Нужно проверять, что прочитанные данные имеют ожидаемый формат.
