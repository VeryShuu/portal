## Общее впечатление

**Сильные стороны:**
- Узнаваемый MAGE-брендинг: navy-палитра + бренд-красный акцент, Inter, hero-градиенты
- Стройная design-system на CSS-переменных ([./frontend/src/styles/tokens.css](./frontend/src/styles/tokens.css))
- Аккуратная иерархия sidebar: `Лента / Работа / Сервисы / Аккаунт`
- Поддержка светлой и тёмной темы
- Глобальный поиск через Ctrl+K
- Skip-link для клавиатурной навигации (`Перейти к содержимому`)

**Главные слабости:**
- **Мобильной вёрстки фактически нет** — sidebar остаётся 240 px на любом экране
- 404-страница ломает layout (теряется навигация)
- Хардкод title «Главная» на странице `/photos` (баг роутинга)
- Несколько визуальных артефактов в dark-теме (логотип, иконки сервисов)
- Hero-блок главной + дублирование поиска занимают слишком много экрана
- Карточки новостей без обложек — все одинаковые градиент-плейсхолдеры
- Empty-states на `/files`, `/photos`, `/profile` бесполезные

## КРИТИЧНЫЕ ПРОБЛЕМЫ (P0)

### P0-1. Мобильной вёрстки нет 🔴

**Файл:** [./frontend/src/components/AppLayout.vue:646-656](./frontend/src/components/AppLayout.vue:646)

**Зачем чинить:** ~30–40 % сотрудников открывают портал с телефона (новости, KB, расписание). Сейчас на 390 px sidebar съедает 60 % экрана, контент режется по правому краю — пользоваться невозможно. Это **блокер релиза мобильной версии**.

**ДО:**
```css
/* Только 2 media-query, прячут поиск и имя юзера */
@media (max-width: 900px) {
  .header-center { display: none; }
  .header-left { min-width: 0; }
  .user-pill__name { display: none; }
  .search-pill { min-width: 0; }
}
@media (max-width: 600px) {
  .app-content { padding: 16px; }
  .lang-text { font-size: 11px; }
}
```
→ Sidebar 240 px виден всегда, контента остаётся ~150 px.

**ПОСЛЕ:**
- `≥ 1024 px`: full-width sidebar 240 px (как сейчас)
- `768–1023 px`: collapsed sidebar 64 px (только иконки, tooltip на hover)
- `< 768 px`: sidebar скрыт, hamburger-кнопка в header → выезжает `<n-drawer placement="left">`
- Опционально (но желательно): bottom-nav на телефонах с топ-3 разделами (Главная / Новости / KB / Поиск)

**Что писать:**
1. Composable `useBreakpoint()` (или взять `@vueuse/core` `useBreakpoints`)
2. `<n-drawer>` для мобильного sidebar, биндинг `v-model:show` к Pinia/local state
3. `aria-controls` + `aria-expanded` на hamburger-кнопке
4. `lock-scroll` + клик по overlay закрывает drawer
5. Обновить media-queries: `@media (max-width: 1023px)` → collapsed; `@media (max-width: 767px)` → drawer
6. Убрать дублирующий футер-юзер из sidebar на мобиле (он есть в header)

**Сложность:** 🔴 Hard (1–2 дня) — затрагивает основной layout, нужно протестировать все страницы

### P0-2. 404-страница без layout 🟢

**Воспроизведение:** открыть `/services` (несуществующий роут).

**Зачем чинить:** пользователь, ткнувший в кривую ссылку, теряет всю навигацию — нет sidebar, нет header, нет даже логотипа. Кнопка «На главную» — единственный выход. Это противоречит принципу **«никогда не теряй пользователя»** (Nielsen).

**ДО:**
```
[пустая серая страница]
🤔
Страница не найдена
[На главную]
```

**ПОСЛЕ:**
```
[Sidebar]  [Header с поиском]
           ┌───────────────────────────┐
           │   🤔                       │
           │   Страница не найдена      │
           │   Запрашиваемая страница... │
           │   [На главную]  [Назад]    │
           └───────────────────────────┘
```

**Что писать:** обернуть `NotFoundPage.vue` в `<AppLayout>` или установить `meta.layout = 'app'` в роут-описании и применять layout условно в `App.vue`.

**Сложность:** 🟢 Easy (30 мин)

### P0-3. Заголовок страницы `/photos` показывает «Главная» 🟢

**Воспроизведение:** перейти в Фотогалерею — в шапке title = «Главная».

**Зачем чинить:** очевидный баг навигации, ломает доверие к продукту. Title в header — главный признак «где я нахожусь».

**Что писать:**
- Использовать `useRoute().meta.title` или `usePageTitle('photos.title')` composable
- Установить `meta.title` в роутах для всех страниц
- В `AppLayout` шапка читает реактивно `route.meta.title`

**Сложность:** 🟢 Easy (15 мин)

### P0-4. Логотип в sidebar при dark-теме превращается в красную точку 🟡

**Воспроизведение:** включить тёмную тему → посмотреть на верх sidebar.

**Зачем чинить:** брендинг ломается, пользователь видит только красный кружок без текста и контейнера. Это первое, что видно при входе в dark-режиме.

**ДО:** `<img src="/logo.svg">` — без альтернативного варианта, маленькая иконка теряется на тёмном фоне.

**ПОСЛЕ:**
- Два варианта SVG: `logo-light.svg` + `logo-dark.svg`
- В `AppLayout` через `useThemeStore()` подставлять нужный
- Альтернатива: единая SVG, где цвета через `currentColor` или CSS-переменные
- Опционально: добавить плашку-фон 8 px padding с `background: rgba(255,255,255,0.08)` в dark

**Сложность:** 🟡 Medium (1–2 ч, нужно нарисовать второй вариант лого или адаптировать существующий)

### P0-5. Иконки сервисов исчезают в dark-теме 🟡

**Воспроизведение:** виджет «Мои сервисы» на главной → карточка «1С» в dark-режиме показывает белый квадрат на белом фоне.

**Зачем чинить:** виджет становится визуально сломанным, иконки сервисов невидимы.

**ДО:** favicon сервиса (`<img>`) кладётся прямо на фон карточки без обёртки.

**ПОСЛЕ:**
```html
<div class="service-icon">
  <img v-if="link.icon_url" :src="link.icon_url" />
  <span v-else class="service-icon__fallback">{{ link.name[0] }}</span>
</div>
```
```css
.service-icon {
  background: var(--color-bg-muted);
  border-radius: var(--radius-md);
  padding: 6px;
  display: grid;
  place-items: center;
}
[data-theme='dark'] .service-icon {
  background: rgba(255, 255, 255, 0.06);
}
```

**Сложность:** 🟡 Medium (1 ч) — нужно править компонент `ServicesWidget` и страницу `/links`

### P1-1. Карточки новостей без обложек 🟡

**Зачем чинить:** все 5 карточек одинаковые цветные градиенты — теряется scannability и визуальная иерархия. Пользователь не может быстро найти нужную новость глазами.

**ДО:** `background: linear-gradient(...)` — детерминированный градиент по hash от title.

**ПОСЛЕ:**
1. Поле `cover_image_url` в `news` (если ещё нет — есть, см. db-schema)
2. Если есть — показывать обложку
3. Если нет — извлекать первое изображение из markdown-контента (на бэке при сохранении)
4. Если нет картинок — gradient + крупная буква категории + иконка
5. Категория-бейдж (`HR/IT/Финансы`) поверх обложки

**Сложность:** 🟡 Medium (3–4 ч) — backend-парсер первого `<img>` + frontend-fallback

### P1-3. Empty-states бесполезные 🟡

**Где:**
- `/files` без выбранной папки → `Выберите папку слева для просмотра файлов` + grey-icon
- `/photos` без выбранной папки → аналогично
- `/profile` поля «Телефон / Отдел / Должность» = `—`
- Виджет «Избранное» с пустой ссылкой = пустой блок + 2 одинаковые CTA-кнопки

**Зачем чинить:** «empty state — это onboarding-экран, а не сообщение об ошибке». Пользователь, который зашёл в раздел впервые, должен сразу понять **что делать**.

**ДО:** иконка + grey-text «Выберите папку».

**ПОСЛЕ (`/files`):**
```
[ Иллюстрация / иконка ]
Загляните в одну из папок слева
или [+ Создайте новую папку] / [⤴ Загрузите файл]

📌 Недавно загруженные:
  • report.pdf — 2 часа назад
  • photo.jpg — вчера

💡 Совет: поддерживается drag-n-drop
```

**ПОСЛЕ (`/profile` пустые поля):**
- `Телефон —` → `[+ Добавить телефон]` (кликабельный inline-edit)
- `Отдел —` → если автозаполнения нет, прятать строку или показывать `Не указан (заполните в Keycloak)` со ссылкой

**Сложность:** 🟡 Medium (1 день) — затрагивает 4 компонента, нужны иллюстрации/иконки

### P1-5. Sticky-header без backdrop-blur 🟢

**Зачем чинить:** при скролле под header виден контент, выглядит «приклеенным». Современный паттерн (Notion, Linear, GitHub) — полупрозрачный фон + blur, контент мягко уходит под шапку.

**ДО:**
```css
.app-header {
  background: var(--color-brand-navy);
  position: sticky;
  top: 0;
}
```

**ПОСЛЕ:**
```css
.app-header {
  background: rgba(11, 42, 74, 0.85);
  backdrop-filter: blur(12px);
  -webkit-backdrop-filter: blur(12px);
  position: sticky;
  top: 0;
}
```

**Сложность:** 🟢 Easy (10 мин)

### P1-6. Контраст muted-text ниже WCAG AA 🟢

**Файл:** [./frontend/src/styles/tokens.css:26](./frontend/src/styles/tokens.css:26)

**Зачем чинить:** `--color-text-subtle: #94a3b8` на `#f5f7fa` даёт contrast ratio ~3.3:1, что **ниже WCAG AA (4.5:1)** для normal-text. Часть текста (даты, метаданные карточек) пользователи с лёгкой пресбиопией читают с трудом.

**ДО:** `--color-text-subtle: #94a3b8;` (3.3:1)

**ПОСЛЕ:** `--color-text-subtle: #64748b;` (4.6:1) — равен `--color-text-muted`. Либо ввести promo-token `--color-text-decorative` для случаев чисто-декоративного текста, не несущего информацию.

**Сложность:** 🟢 Easy (5 мин + быстрая проверка скриншотов)

---

### P1-7. Приветствие «Administrator» вместо имени 🟢

**Зачем чинить:** на главной hero-приветствие — **первое впечатление** при каждом входе. «Доброй ночи, Administrator» — это явно системная метка, а не имя.

**ДО:** `t('home.greeting', { name: user.full_name })` где `full_name = "Administrator"`.

**ПОСЛЕ:**
```ts
const displayName = computed(() =>
  user.first_name || user.full_name?.split(' ')[0] || t('home.greeting_anonymous')
);
```

**Сложность:** 🟢 Easy (15 мин)

## Предложения по новым фичам

### F-1. Виджеты главной (приоритет: высокий) 🟡

**Зачем:** превратить главную из «список новостей» в **дашборд жизни компании**, как у IBM Connections / Workplace from Meta / Bitrix24.

**Виджеты:**
- 🎂 **Дни рождения / новые сотрудники** — список из 1–3 коллег с аватаром + кнопка «Поздравить»
- 📍 **Сегодня в офисе / на удалёнке** — статус коллег (поле `users.preferences.status` уже есть)
- 📊 **Опросы / голосования** — короткий poll-виджет (1 вопрос, кнопки)
- 💚 **Health корпоративных сервисов** — статус 1С, Nextcloud, почты (зелёный/жёлтый/красный)
- ⚡ **Быстрые действия** — заявка в ОИТ / в HR / отпуск (deeplink в 1С)
- 📅 **События недели** — день рождения компании, корпоратив, тренинг

**Сложность:** 🟡 Medium (1–2 недели на 6 виджетов, по 4–8 часов каждый)

---

### F-2. Расширить Cmd-K палитру 🟢

**Зачем:** сейчас Ctrl+K — только поиск. У продвинутых юзеров (~10–15 % сотрудников) это будет основной способ навигации.

**Команды:**
- `> создать новость` — переход на форму
- `> перейти в KB → Регламенты`
- `> сменить тему`
- `> выйти`
- `> экспорт KB-статьи`

**Реализация:** библиотека `cmdk-vue` или собственный компонент, типа Linear/Raycast.

**Сложность:** 🟡 Medium (1 день)

---

### F-3. Drawer уведомлений 🟡

**Зачем:** колокольчик в header уже есть, но не видно UX. Стандарт (Slack, GitHub, Telegram-web): клик → drawer справа со списком.

**Возможности:**
- Группировка по дням («Сегодня / Вчера / На этой неделе»)
- Фильтры (упоминания / ответы / системные)
- «Отметить все прочитанными»
- Клик по уведомлению → переход к источнику + закрытие drawer

**Сложность:** 🟡 Medium (1–2 дня)

---

### F-4. Кастомизация дашборда 🔴

**Зачем:** разные роли (HR / разработчик / руководитель) хотят разные виджеты. Сейчас всё захардкожено.

**Реализация:**
- Drag-and-drop виджетов (vue-draggable / sortable.js)
- Сохранение порядка в `users.preferences.dashboard_layout: ["news", "birthdays", "kpi", ...]`
- Кнопка «Настроить дашборд» открывает редактор

**Сложность:** 🔴 Hard (3–5 дней)

---

### F-5. Onboarding-tour 🟡

**Зачем:** при первом входе пользователь не знает, **где что** в портале. 80 % новых сотрудников пропустят 60 % функций.

**Реализация:** `shepherd.js` или `intro.js`, 5–7 шагов:
1. «Здесь живёт лента новостей»
2. «База знаний — Ctrl+K для быстрого поиска»
3. «Сервисы — все ярлыки в одном месте»
4. «Закладки — сохраняй важное»
5. «Профиль — расскажи о себе»

Хранить флаг `users.preferences.onboarding_completed` в JSONB.

**Сложность:** 🟡 Medium (1–2 дня)

---

### F-6. PWA + Offline 🔴

**Зачем:** для интранета на VPN — иконка приложения на телефоне, оффлайн-доступ к закэшированным KB-статьям и фото.

**Реализация:**
- `vite-plugin-pwa` (плагин Vite)
- `manifest.json` с иконками 192/512
- Service Worker с workbox: кэш KB-статей, аватаров, статики
- Background sync для black-out новостей

**Сложность:** 🔴 Hard (3–5 дней + тестирование)

## Доступность и a11y

| # | Проблема | Решение | Сложность |
|---|----------|---------|-----------|
| A11y-1 | Нет `prefers-reduced-motion` | `@media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } }` | 🟢 |
| A11y-2 | `:focus-visible` не везде явный | Глобально: `:focus-visible { outline: 2px solid var(--color-brand-red); outline-offset: 2px; }` | 🟢 |
| A11y-3 | На login нет `<form>` + `autocomplete` | Обернуть поля, поставить `autocomplete="email"` / `current-password` | 🟢 |
| A11y-4 | Контраст muted-text (см. P1-6) | См. P1-6 | 🟢 |
| A11y-5 | Hamburger (когда появится) без `aria-controls` | Добавить `aria-controls="sidebar-drawer"` + `aria-expanded` | 🟢 |
| A11y-6 | Skip-link есть — это плюс ✅ | — | — |
| A11y-7 | Drawer/modal — нет focus-trap | Naive UI `<n-drawer>` это умеет, проверить включение | 🟢 |
| A11y-8 | Иконки-кнопки без `aria-label` | Проверить все `<button><svg/></button>` — есть `aria-label` (поиск, тема, уведомления уже есть ✅) | 🟢 |
