# UI/UX план корпоративного портала

> Документ описывает план редизайна интерфейса корпоративного портала на основе брендбука АО «МАГЭ» ([mage.ru](https://mage.ru/ru/)) и лучших практик интранетов 2025–2026.
> Техническая база: Vue 3 + TypeScript + Naive UI + Pinia + vue-i18n (без смены стека).

---

## 1. Брендбук МАГЭ → портал

### 1.1. Анализ источника

С сайта `mage.ru` взяты следующие визуальные признаки:

| Элемент | Характеристика |
|---------|----------------|
| **Акцентный цвет** | Корпоративный **красный** — используется для ключевых цифр (55 лет, 100 проектов), CTA, акцентов |
| **Базовый цвет** | **Тёмно-синий** (море, логотип МАГЭ) — «морская/арктическая» индустриальная тональность |
| **Доп. цвет** | **Светло-голубой** (волны в лого) — вспомогательный, для иконок, иллюстраций |
| **Фон** | Чистый белый / светло-серый, много воздуха |
| **Типографика** | Строгая гротеск sans-serif, **UPPERCASE** для надзаголовков и секций, Bold для цифр |
| **Фото** | Арктика, корабли, лёд, море — серьёзно, без гламура |
| **Настроение** | Консервативное, индустриальное, надёжное, серьёзное |

### 1.2. Палитра портала

```
--color-brand-red:      #D8262C   /* акцентный, CTA, важное */
--color-brand-red-dark: #A81D23   /* hover */
--color-brand-navy:     #0B2A4A   /* основной тёмно-синий, шапки, sidebar */
--color-brand-navy-2:   #143A66   /* градиенты, depth */
--color-brand-sky:      #4A90C4   /* вспомогательный, иконки, ссылки */
--color-brand-ice:      #E8F1F8   /* светлая подложка блоков */

--color-surface:        #FFFFFF
--color-bg:             #F5F7FA
--color-border:         #E2E8F0
--color-text:           #0F172A
--color-text-muted:     #64748B

/* Dark mode */
--dark-surface:         #0F1E33
--dark-bg:              #071426
--dark-border:          #1E3252
--dark-text:            #E6EEF8
```

Сохраняем существующие Naive UI `theme-overrides` API — просто переопределяем `primaryColor`, `infoColor`, `borderRadius` и ряд токенов.

### 1.3. Типографика

- **Заголовки**: `Inter` 700/800, отрицательный letter-spacing, UPPERCASE для h5/h6 и меток секций (как на mage.ru).
- **Body**: `Inter` 400/500, 15px, line-height 1.6.
- **Цифры/статистика**: крупные (32–56px), Bold, красные — как «55 лет» и «100 проектов» на сайте МАГЭ.
- Подключаем шрифт через `@fontsource/inter` (offline, без CDN — на VPN/внутренней сети это критично).

### 1.4. Формы и тени

- `border-radius`: 8px для кнопок и инпутов, 12px для карточек, 16px для hero.
- Тени тонкие, «морские холодные»: `0 1px 2px rgba(11,42,74,.06), 0 4px 16px rgba(11,42,74,.08)`.
- Границы 1px `#E2E8F0`, в dark — `#1E3252`.

Компоненты:

- `TopArticlesWidget.vue` — 3–5 популярных статей KB.

### 2.2. Шапка (`AppLayout.vue`)

Было: серая, плоская, с приветствием в виде текста.
Будет:
- Фон: **тёмно-синий navy** (#0B2A4A), белый текст — это сразу даёт «корпоративность» МАГЭ.
- Слева: breadcrumbs текущей страницы (на главной — логотип компании).
- По центру: компактное поле поиска с подсказкой `Ctrl+K`.
- Справа: bell-icon с бейджем непрочитанных, переключатель темы, RU/EN, аватар с dropdown.
- Высота 56–60px.

### 2.3. Сайдбар

- Фон: более светлый чем шапка — либо белый, либо `#F5F7FA`.
- Логотип компании (полный) сверху, 60px высота.
- Группировка пунктов с mini-заголовками UPPERCASE (как секции на mage.ru):
  ```
  ЛЕНТА
  └ Главная
  └ Новости
  РАБОТА
  └ База знаний
  └ Файлы
  СЕРВИСЫ
  └ Корпоративные сервисы
  └ Закладки
  АККАУНТ
  └ Профиль
  └ Администрирование (только admin)
  ```
- Активный пункт: **красная вертикальная полоса 3px слева + светло-красная подложка**.
- Бейджи непрочитанного у «Новости» и «Уведомления».
- Внизу блок пользователя: аватар + ФИО + должность. В collapsed — только аватар.
- Ширина 240px / collapsed 64px. Сохранение состояния в localStorage.

### 2.4. Новости

- **Лента** (`/news`): сетка 3 колонки на desktop, 2 — на tablet, 1 — на mobile.
- **Детальная** (`/news/:id`): ширина контента 720–800px (читабельно), cover изображение сверху 100% ширины, метаданные под заголовком, кнопка «Поделиться копированием ссылки».
- **Форма** (`/news/create`): 2 колонки — слева редактор, справа сайдбар с настройками (статус, таргетинг, publish_at, cover image). Поддержка sticky-сайдбара при прокрутке.
- Бейджи категорий — пастельные подложки:
  - HR → персиковый `#FFE4E1`
  - IT → голубой `#E0EAFC`
  - Финансы → лавандовый `#EDE4FF`
  - Общее → серый `#F1F5F9`

### 2.5. База знаний (будущее, Phase 3)

- Левая колонка: **дерево разделов** (`n-tree` с кастомной иконкой) 260px.
- Центр: контент статьи с breadcrumbs и TOC (table of contents) справа sticky.
- Под статьёй: «Статья полезна?» (helpful/not helpful), теги, последние правки.

### 2.6. Страница входа (`/login`)

- Split-screen 50/50:
  - **Левая половина**: фото Арктики (cover), overlay с логотипом и слоганом «От Арктики до Антарктики».
  - **Правая половина**: белая форма: `Войти через Keycloak (SSO)` — крупная primary-кнопка, ниже разделитель «или», ниже форма локального логина (email + password).
- Фон правой половины: мягкий градиент навыход белый → `--color-brand-ice`.
- Форма ограничена 360px, всё по центру.

## 5. UX-улучшения

1. **Глобальный поиск Ctrl+K / ⌘K** — палетта в стиле Raycast/Linear: статьи, люди, файлы, действия. Открывается из любого места. Поддержка стрелок и Enter.
2. **Skeleton-лоадеры** вместо `n-spin` на главной и в ленте новостей.
3. **Пустые состояния** с векторной иллюстрацией (SVG, монохром navy+red) + CTA. Примеры: «Закладок пока нет → Добавить первую».
4. **Toast-уведомления** (Naive UI `useMessage`) для всех успешных действий.
5. **Breadcrumbs** на всех вложенных страницах (новости, KB, профиль).
6. **Sticky header** при прокрутке длинных страниц.
7. **Sticky TOC** в статьях KB.
8. **Responsive**:
   - ≥1200px — 3 колонки
   - 900–1199px — 2 колонки, правая колонка ниже
   - <900px — 1 колонка, sidebar collapsible
   - <640px — sidebar → bottom tabs (5 пунктов)
9. **Focus states** — красная обводка 2px для доступности (WCAG AA).
10. **Reduced motion** — респект `prefers-reduced-motion`.
11. **Dark mode** — аккуратный, с приглушённым градиентом hero.
12. **Анимации** — только `transition` для hover/focus, никаких jumpy JS-анимаций.

## 6. Иллюстрации и изображения

- **Hero паттерн**: SVG-волны в стиле лого МАГЭ (голубые, низкая opacity).
- **Empty states**: 4–5 монохромных SVG (navy + red accent): «нет новостей», «нет закладок», «ничего не найдено», «нет доступа», «ошибка».
- **Фото Арктики для login**: 1 качественное фото (cover), оптимизировать в WebP, ≤200KB.
- **Cover images новостей**: рекомендация 1600×900, fallback — градиент navy→sky с иконкой категории.
- Всё хранится локально в `frontend/src/assets/` — без CDN (внутренняя сеть).

## 7. Адаптивность и производительность

- CSS-переменные для палитры → мгновенное переключение темы.
- `font-display: swap` для Inter.
- Lazy-loading изображений новостей (`loading="lazy"`).
- Images в WebP с fallback JPEG через `<picture>`.
- Все иконки из одного chunk (`@vicons/ionicons5` tree-shakable).
- Route-level code splitting уже работает (Vite).

---

## 8. Доступность (a11y)

- Контраст текста ≥ 4.5:1 (проверить через axe-core).
- Все интерактивные элементы имеют `:focus-visible` с видимой обводкой.
- `aria-label` для кнопок-иконок (bell, theme toggle, lang switch).
- `aria-live="polite"` для toast-уведомлений.
- Клавиатурная навигация: Tab, Enter, Esc работают везде.
- Skip-to-content link в начале страницы.
- Поддержка screen readers для динамических списков.

## 10. Что за рамками этого плана

- **Блок «Коллеги рядом» / дни рождения** — по решению заказчика, не делаем.
- **Виджет погоды / курсов валют** — по решению заказчика, не делаем.
- **Анимированные иллюстрации (Lottie)** — избыточно для корпоратива МАГЭ, не делаем.
- **3D / WebGL эффекты** — не соответствует консервативному брендингу.

## 11. Критерии приёмки дизайна

1. Все экраны используют палитру МАГЭ (navy + red + ice), без «стокового» зелёного Naive UI.
2. Главная перестала выглядеть «пустой»: hero + виджеты + лента занимают видимую область без скролла на 1440×900.
3. Шапка и сайдбар чётко разделены визуально (navy vs white).
4. На всех пустых состояниях есть иллюстрация + CTA.
5. Skeleton-лоадеры показываются при загрузке, `n-spin` остался только в диалогах действий.
6. Глобальный поиск открывается по Ctrl+K на всех страницах.
7. На ширине 360–1920 px интерфейс не ломается, тексты не обрезаются.
8. Контраст текста ≥ 4.5:1, доступность проходит axe-core без critical issues.
9. Тёмная тема реализована и не «ломается» ни на одной странице.
10. Все строки интерфейса присутствуют в `ru.json` и `en.json`.
